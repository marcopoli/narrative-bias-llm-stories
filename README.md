# Positive Tone Hides Unequal Agency in Stories Written by Large Language Models

Data and code for the article of the same title (under review). The repository holds all 10,770 generated stories,
their scores, the LLM ratings and pairwise judgements, and the scripts that reproduce every statistic, table and figure
of the article and of Online Resource 1.

## Contents

| Folder | What it holds |
|---|---|
| `analysis/` | `master_results.db`: the main corpus (4,500 stories of Gemma 3 4B, Llama 3 8B and Mistral 7B, 75 personas, with all story-level scores). Scripts for the main analysis and the robustness checks, with their outputs in `results/`. |
| `experiments/` | The follow-up experiments (6,270 stories). Generation, scoring, rating and analysis scripts; `out/` holds the stories, ratings and pairwise judgements as JSONL; `results/` holds the outputs; `norms/` holds the external occupation data. |
| `figures/` | Figures 1 to 4 and S1 to S5 (PNG, PDF, EPS). |
| `corpus_generation/` | The code that generated and scored the main corpus: generators, the four measures (P1 to P4), the merge step and the first statistical pipeline. `data/` holds the per-model databases before merging. |

## Story files

Each line of `experiments/out/stories_<experiment>_<model>.jsonl` is one story with its persona (profession, gender,
nationality), the prompt condition, the seed and the text. `ratings_*.jsonl` are the LLM ratings of masked texts
(Experiment 3), and `pairs_*.jsonl` the pairwise agency judgements (Experiment 5).

## Reproducing the results

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_lg
python analysis/reproduce_analysis.py          # main corpus, Tables, Fig. S1 to S5
python analysis/robustness_nlp.py              # robustness checks (re-parses the corpus)
python analysis/robustness_summary.py
python experiments/score_new.py                # scores of the follow-up stories
python experiments/analyze_experiments.py      # Experiments 1 to 3
python experiments/analyze_45.py               # Experiments 4 and 5
python experiments/standard_audit.py           # standard toxicity and regard check
python experiments/flagged_sentences.py        # sentences behind the toxicity flags
python experiments/final_tables.py             # all numbers of the article (results/final_numbers.json)
python experiments/supplement_45.py            # Sections S4 and S5 of Online Resource 1
python experiments/figures.py                  # Figures 1 to 4
```

The scoring and analysis steps need no GPU. Story generation, LLM ratings and pairwise judgements used Ollama
(https://ollama.com) with the model tags given in the article; `run_*.sh` show the exact calls, run at low priority on
shared machines. All sampling uses fixed seeds. Exact p values were checked with scipy 1.18.0, numpy 2.4.2 and pandas 3.0.0;
other versions can change the last digits.

## External data

The occupation norms come from published, anonymised group-level data (see `experiments/norms/README.md`):
Friehs et al. (2022) for warmth and competence, and Hughes et al. (2024) for occupational prestige.
